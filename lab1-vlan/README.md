# Lab 1 — VLANs + Router-on-a-Stick

## Objective

Build a small office network with two VLANs across two switches and route traffic between them using a single router interface (router-on-a-stick).

**Skills practiced:**
- VLAN creation and port assignment
- 802.1Q trunking between switches
- Native VLAN configuration
- Router-on-a-stick (sub-interfaces with 802.1Q encapsulation)
- Management VLAN (VLAN 99) for switch access
- End-to-end connectivity testing
